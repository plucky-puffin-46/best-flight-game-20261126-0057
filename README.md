Puffin Air Rally is a browser flight game: pilot the little prop plane Puffin One over an island archipelago, thread eight glowing rings in order, then land back on the runway for a judged score. Chase and cockpit views, live instruments, stall and fuel — all in one static page, with no build step and no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.

## How to play

Take off from the runway, follow the steering arrow through all eight rings in
order, and land back on the strip: a soft, centred, aligned touchdown scores
best. Watch your fuel, and mind the stall — below flying speed the nose drops.

- Arrow keys: pitch and roll · W/S: throttle
- A/D and Q/E: roll and rudder trim · C: chase / cockpit camera
- M: mouse steering · P: pause · R: restart · Enter or click: start

`node main.ts` (with `MAKEFUN_OUTPUT_DIR` set) packages the game and the
screenshots into an output directory with its dossier, the way the bounty
scores it.
